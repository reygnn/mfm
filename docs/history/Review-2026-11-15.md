# Review 2026-11-15

Four reviewers on main at 0e09085, one part of mfm.c each: buffers, UTF-8, colours,
settings and the directory; spawning, renames, the trash and the worker; the session
clipboard, navigation and text input; drawing, the menu, Wayland input and the tests.
Nothing overwrote or silently lost data. Each finding was checked against the code
before it was listed.

## Status

All points settled on fix/review-2026-11-15. A test that fails without its fix was
checked by taking each fix out in turn and running the suite. Points without a test
say why.

## Defects

1. **Delete moved a folder with a mount in it to the trash.** `trash_one()` checked
   `is_mount()` only. Emptying the trash later empties what is mounted. Fixed with
   `mount_below()`, as for permanent deletion. Test in files.sh.
2. **A job waited for EOF on the stderr of its program, not for its end.** An
   MFM_SEND script that leaves something running in the background kept the job
   alive, and with it the block on paste, delete, F2 and F7. `wait_prog()` now waits on
   a pidfd. The program also gets SIGPIPE back, and /dev/null no longer leaks into it.
   Test in ui.sh.
3. **A new name starting with a dot vanished, and the selection moved to a neighbour**,
   which Delete would then trash. F2 and F7 now show hidden files for such a name, as
   `go_to()` does. Test in ui.sh.
4. **The wheel cancelled F2, F7, the path field and the question before deleting.** It
   now only scrolls. Test in ui.sh.
5. **A failed move of a read-only folder to another file system named the wrong side
   as incomplete.** `mv` copied all, could not empty the source and left the complete
   copy in the hidden folder. Such a move is now `cp -a`, placed under its name, then
   the original removed, with u+w if needed. A failed copy is cleaned up and the source
   is untouched. Tests in files.sh: the full disk, and a read-only folder with a file.

## Tests that could not fail

6. **`job_settled` passed before the worker had started.** The checks after it mostly
   asked that something still exists. Every refusal now shares its job with a sentinel
   that must arrive or go; positive checks wait with `wait_for`.
7. **`check '! clipget types'` was true on the first try.** Ctrl+V after Ctrl+C now
   proves the key was handled first.
8. **ui.sh did not check that the menu was closed, nor which row a click beside it
   left selected.** Both now rename something and wait for it.

## Smaller points

9. **`rc_get()` let a value too long replace the one before**, truncated, and read the
   rest of a line longer than 1023 bytes as a line of its own. Both are skipped now.
   Test in ui.sh.
10. **`parse_color()` took a sign, blanks and `0x` in `rgb:`.** Each part must start
    with a hex digit. Test in ui.sh.
11. **Ctrl and Alt shortcuts did nothing on a Cyrillic or Greek layout.** They now take
    the key's Latin letter from the first layout that has one. No test: vinput knows
    only the us layout.
12. **Holding Space marked a run of rows, holding Backspace or Left climbed to /.** They
    repeat only in input fields and, for Backspace and Space, in a search. Test in
    ui.sh. mfm.1 lists what repeats.
13. **mfm.1 said Right opens files.** It opens folders only; the man page says so.
14. **Size order reversed the folders and the names of equal sizes.** Folders stay A to
    Z, ties by name; only the order the key chose is reversed. Folders mfm cannot stat
    no longer sort last among folders. Test in ui.sh.
15. **The session clipboard:**
    - The marks were dropped before the export was tried; now only after it worked.
    - After two seconds without an answer the helper was left running; it is killed.
    - A name that is not UTF-8 went out as `text/plain;charset=utf-8`; such a set is
      offered as URLs only. Test in ui.sh.
    - The helper blocked for good on a reader that stopped reading. It gives up after
      five seconds without progress.
    The first, second and fourth need a compositor that fails on purpose; no test.
16. **Unicode:**
    - `disp()` let valid C0 and C1 controls, U+200B, U+2028, U+2029 and U+FEFF through;
      they become U+FFFD.
    - Delete and Backspace removed a code point, not the letter with its marks. Test in
      ui.sh.
    - Marks were only the generic combining blocks; `g_unichar_ismark()` covers every
      script, plus the emoji joiner and skin tones. Test in ui.sh (Devanagari).
    - Type-ahead did not match a decomposed name; both sides are compared NFC.
    - `human()` printed "1024.0 K" at the unit boundaries.
    No test for the first, the fourth and the fifth: they show only in pixels, or need
    keys vinput cannot type.

## Also fixed

  changes its "..". It gets u+w for the rename, as for a move. Test in files.sh.
- `poll_dir()` climbed every second again after a climb had found nothing listable,
  and never again once the folder had been listable in between.
- A seat that loses its pointer or keyboard without a leave kept a drag, held buttons
  or Ctrl.

No test for the last two: they need "/" unlistable or a seat losing a device.
