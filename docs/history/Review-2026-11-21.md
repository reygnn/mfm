# Review 2026-11-21

A review of mtk 0.8.0 by eight reviewers, each finding checked by an adversarial
verifier: 26 confirmed, 23 once duplicates are merged, one uncertain and one refuted.
All 23 are settled in mtk 0.9.0, one of them in pulseControl. Every fix has a test
that fails without it.


## Loop and windows (wl.c)

- A timer cancelled by an earlier callback of the same round still ran. Each due
  timer is now run only if its slot still holds it.
- `mtk_run()` counted the watched fds before the idle hook, so an fd unwatched there
  was polled twice for a round. It counts them after.
- A key repeat begun in a grabbing popup went on into its parent once the popup was
  gone. The repeat belongs to the window the press went to and stops with it.
- `configure` and `scale` called into the client before mtk was done with the
  window, so a window destroyed there was used after its free. They come last.
- The demo now uses every function of the Wayland side; `tests/ui.sh` checks each.

## Input

- `mtk_latin_sym()` turned Latin-1 punctuation into a letter of another layout.
  It now looks at other layouts only for keysyms outside Latin-1, as Qt does, and
  takes the active layout.
- pulseControl read `latin` for plain keys, so `-` on AZERTY opened the field with 6.
  It reads the key's own symbol unless Ctrl is held or the letter is outside Latin-1
  (branch `fix/azerty-keys` in pulseControl).
- The grapheme step after a byte that is no UTF-8 went right over the byte and its
  marks, left only to the marks. Both now take them as one.
- Without memory, `mtk_field_key()` dropped Return, Esc and the cursor keys too.
  Only edits need memory now.

## Colours and the mwmrc

- Colours given with more than 8 bits were rounded to 8, where mwc cuts them to the
  high byte. mtk cuts them as mwc 9941a47 does, and decides on those 8 bits.
- An empty `HOME` gave no mwmrc; mwc reads `/.config/mwc/mwmrc`, and so does mtk.

## Drawing

- A font without a size had no metrics, and the field drew its text too high.
  `mtk_font()` gives such a font 10 points, and `mtk_field_draw()` takes the layout's
  own line when the metrics are zero.
- `mtk_font()` rejected fontconfig's other generic names (mono, system-ui, ...).
- `mtk_damage_rows()` counted a gap one row too wide, and gap 0 split rows that
  touch. It counts the unchanged rows between two runs; `mtk.h` says so.

## Build, documentation, tests

- A client written as the README showed built only `build/mtk`. `mtk.mk` keeps the
  client's default goal, and the examples put `all: app` first. `tests/mk.sh`, in
  `make check`, builds such a client.
- The units did not depend on the modules they link with, and went stale.
- CAVEATS said a window past 32767 pixels stays black; it is drawn cut.
- `mtk_key_quits()` and `mtk_quit()` are described as they behave; the demo's own
  loop ends on the compositor's close.
- Tests that could not fail now can: the compose test without a table, the cursor
  inside a grapheme, the compositor's size, a modifier pressed while a key repeats.
