# Review 2026-11-17: eight topics

Eight reviewers read mfm on main at 809cc46, one topic each: memory management,
performance, robustness, the hot path, hacks, happy and sad path tests, data safety of
file operations, and Wayland protocol correctness. Points the two reviews of
2026-11-15 or CAVEATS.md had already settled were left out.

## Status

All points settled on fix/review-2026-11-17. A test that fails without its fix was
checked by taking each fix out in turn and running the suite. Points without a test
say why. The suite went from 324 to 446 checks.

## Data safety

1. **A name with a newline went to the clipboard as text.** One path per line made it
   two, and pasted into a terminal the second ran as a command. Paths with a control
   character now go as URLs only. Test: such a name offers no `text/plain`.
2. **`chmod -R u+w` followed a link.** When the original of a move to another file
   system could not be removed, chmod made the link's target tree writable. Now only
   for a folder. Test: a link in a read-only folder, to a read-only folder.
3. **After a partly failed move the whole clipboard stayed**, and a second Ctrl+V moved
   what had come up under the moved names since. The worker names each item that
   failed with its original whole (`JOB_KEEP` lines); only those stay. `report()`
   replaces control characters, so no file name can fake such a line. Test: a new
   file under a moved name stays where it is.
4. **FAT and exFAT failed every copy**, as `cp -a` fails on each permission it cannot
   set. A temporary folder that does not show the 0700 it was made with marks such a
   file system, and there `cp -R --preserve=timestamps` copies. No test: the test box
   cannot mount FAT. Links on FAT are in CAVEATS.
5. **A file added to the original during a move to another file system is removed
   with it**, as with `mv`. CAVEATS.
6. **A link on the logical path pointed elsewhere** makes the next action happen in
   the new place. Contrived; CAVEATS.

## Robustness

7. **A failed `.trashinfo` write said EIO**, not ENOSPC or whatever it was. No test:
   the tests read the status line by colour, not by text.
8. **A worker that died did not say where its partial copy was.** The message names
   the hidden `.mfm-*` folder. No test, as 7.
9. **btrfs subvolumes not mounted on their own failed to trash**: the mount ID is the
   same, rename gives EXDEV, and the topdir walk went past the subvolume. The trash
   compares the device too. No test: no btrfs in the test box. CAVEATS has the rest.
10. **A hung network file system freezes the window.** Moving all stat work to another
    process is out of proportion; CAVEATS.

## Performance and hot path

11. **Each row was shaped by Pango about eight times a frame.** Text is shaped once
    and drawn from that layout; the widths of `...`, date and size are measured once.
    No new test: the drawing tests cover the output.
12. **Type-ahead normalized every name, and the search, on every key.** The search is
    normalized once, an ASCII name not at all. Covered by the type-ahead tests.
13. **Each frame damaged the whole window.** Only rows that differ from the buffer last
    committed are damaged; the next frame goes to the other buffer, which keeps the
    one shown to compare with. Test from the protocol log.
14. **Wheel and scroll bar redrew when nothing moved.** `scroll_to()` sets `dirty` only
    on a change. No test: a redraw that changes nothing shows nothing.
15. **A large folder that keeps changing was read and sorted every second.** Sorting
    compares `strxfrm` keys made once per name, and a folder that takes long to read
    is polled no more often than every fourth of that time. No test: timing.
16. **Trash read `/proc/self/mountinfo` once per folder.** Once per trash, sorted, with
    a binary search. Covered by the mount tests in files.sh.

## Memory

17. **`draw_input()` could read an unset `PangoRectangle`** when a cut fell short of
    the cursor. Set to zero, and the cut goes to the cursor. No test: it needs a
    shaping where a shorter prefix is wider.
18. **`theme_init()` kept a reference to its PangoContext.** Dropped.

## Wayland

19. **The buffer size had no limit.** The scale is lowered until a side fits Cairo's
    32767 pixels and a pool stays below 2 GiB. No test: mwc sends no such size.
20. **A seat announced before the one in use was never taken** when that one went.
    Seats announced meanwhile are remembered. No test: mwc has one seat.
21. **A failed first roundtrip was reported as a missing global.** Now as a lost
    connection.

## Hacks

22. **`rename_lost` was a global passing a result back.** `rename_via_tmp()` returns -2.
23. **The date column showed above 420 pixels**, whatever the font. It shows where the
    name keeps at least as much room as the date takes. Test: Sans Bold 24 in the
    default window leaves it out, maximized it shows.

## Tests

24. **Missing paths**, each with a test now: a move within one file system next to a
    taken name, F2 onto a taken name and onto a hard link of the same file,
    Shift+Delete answered with n, a folder pasted into its own subfolder, F7 and F2 in
    a read-only folder and F7 onto a taken name, two files of one name in the trash, a
    file and a missing path as argument, `-v`, an `MFM_OPEN` or `MFM_SEND` that cannot
    run, the path field, copying and moving a name that is not UTF-8, Shift+click
    ranges and Ctrl+A twice. Not tested: `~` in the path field, as vinput has no key
    for it, and anything that needs a compositor without ext-data-control-v1.
25. **Waits that could pass while mfm was behind.**
    - The menu test accepted either outcome of press, drag and release. On mwc the
      release arrives and runs Open, and that is asserted.
    - The negative menu checks know a release was handled when Down lights the first
      item.
    - The drag test never moved inside after coming back, so a drag that went on could
      not show. Checked by taking out the end of the drag.
    - The worker test waits for the hanging cp and the error after the kill.
    - Fixed sleeps until the menu showed, after Return, and for the poll are gone.
    - `TYPEAHEAD_MS` is read from mfm.c.
